# Dashboard Frontend

The security operations dashboard is a React application that surfaces incident queues, sandbox artifacts, analyst feedback workflows, and performance metrics.

## Planned Stack

- React 18 with TypeScript
- Vite build tooling
- Chakra UI (or Material UI) component library
- Recharts / ECharts for analytics visualizations
- WebSocket client for live updates
- Auth via JWT / OAuth2 proxy

## Initial Setup (planned)

1. `pnpm install`
2. `pnpm run dev`
3. Configure environment variables in `.env.local` for API base URLs and WebSocket endpoints.

Implementation will be tracked in future milestones.
